Tailscale (zalecane)

Prywatna, szyfrowana sieć między Twoimi urządzeniami. Nie trzeba otwierać portów na routerze. Darmowy plan wystarcza małej firmie.

  1. Załóż konto na tailscale.com i zainstaluj Tailscale na tym komputerze{% if not st.tailscale %} (Windows: instalator; Linux: curl -fsSL https://tailscale.com/install.sh | sh, potem sudo tailscale up){% endif %}.
  2. Zainstaluj aplikację Tailscale na telefonach i zaloguj się tym samym kontem (lub zaproś pracowników).
  3. W panelu Tailscale włącz MagicDNS i HTTPS Certificates.
  4. Naciśnij przycisk poniżej (albo wpisz tailscale serve --bg {{ port }}). Program będzie dostępny pod https://{{ st.ts_name or "nazwa-komputera.twoja-siec.ts.net" }}.

Cloudflare Tunnel

Dostęp przez zwykłą przeglądarkę bez instalowania aplikacji na telefonach. Wymaga darmowego konta Cloudflare; na stałe – własnej domeny.

  1. Zainstaluj cloudflared.
  2. Szybki test (adres tymczasowy): cloudflared tunnel --url http://localhost:{{ port }} – w oknie pojawi się adres https://…trycloudflare.com.
  3. Na stałe: w panelu Cloudflare Zero Trust utwórz tunel, skieruj go na http://localhost:{{ port }} i zainstaluj go jako usługę poleceniem pokazanym w panelu.
  4. Wpisz adres tunelu w polu „Adres publiczny” powyżej. Opcjonalnie dodaj Cloudflare Access (logowanie e-mailem) jako dodatkową ochronę.

Własny serwer pośredniczący

Jeśli firma ma własną domenę i serwer, ustaw Caddy lub nginx jako serwer pośredniczący z HTTPS na http://127.0.0.1:{{ port }}. Przykład dla Caddy: niezapominajka.firma.pl { reverse_proxy 127.0.0.1:{{ port }} }. Nie przekierowuj portu {{ port }} z routera bez HTTPS.
